2차

O(2ⁿ)
지수
 n이 1 증가할 때마다 단계 수가 2배로 폭증. 완전탐색(brute force) 방식에서 주로 나타남.

정렬 알고리즘 — 단계별 동작

2과목

탭 눌러가며 각 정렬의 동작을 단계별로 확인해봐! 주황색 = 비교 중, 초록색 = 정렬 완료, 분홍색 = 피벗.

비용 산정 — 비관치 · 낙관치 · 기대치 (LOC)

5과목
용어설명
낙관치
가장 적게 나올 것으로 예측한 라인 수 (제일 잘 풀렸을 때).
기대치
가장 많이 나올 확률이 높은(중간) 라인 수.
비관치
가장 많게 나올 것으로 예측한 라인 수 (제일 안 풀렸을 때).
예측치
공식 ★계산
 ( 낙관치 + 4×기대치 + 비관치 ) ÷ 6
예: (2,000 + 4×5,000 + 8,000) ÷ 6 = 5,000 라인
📌같이 나오는 공식노력(인월) = LOC ÷ 1인당 월평균 생산 라인 · 개발 기간 = 노력 ÷ 투입 인원 · PERT 일정 공식도 (낙관+4×기대+비관)/6 동일

페이지 교체 알고리즘

4과목
용어설명 + 키워드
FIFO
First In First Out
 가장 먼저 들어온 페이지를 교체. 들어온 순서만 기억하면 됨.
큐 방식구현 간단성능은 낮음
LRU
Least Recently Used
 가장 오래 사용되지 않은(마지막 사용이 제일 옛날인) 페이지를 교체.
시간 기준카운터·스택으로 구현
LFU
Least Frequently Used
 사용(참조) 횟수가 가장 적은 페이지를 교체.
횟수 기준최근 로드 페이지가 불리
NUR
Not Used Recently
 최근에 사용되지 않은 페이지를 교체 — 비트 2개로 판단 (참조 비트, 변형 비트 모두 0이면 우선 교체).
참조 비트변형 비트LRU 근사
OPT
Optimal
 앞으로 가장 오랫동안 사용하지 않을 페이지를 교체. 미래를 알아야 해서 실제 구현 불가 — 비교 기준용.
이론상 최적실현 불가능
벨레이디의
모순
Belady's Anomaly ★함정
 프레임(페이지 수용 칸)을 늘렸는데 결함이 오히려 증가하는 현상. FIFO에서만 발생.
FIFO에서 발생"많을수록 좋다"가 깨짐
헷갈림 세트구분 기준 한 줄
LRU
시간 — 마지막으로 쓴 지 가장 오래된 것 Recently = 시간
LFU
횟수 — 지금까지 쓴 횟수가 가장 적은 것 Frequently = 빈도
NUR
비트 — 참조·변형 비트 (0,0)부터 교체 비트 2개

참조 순서:

📌결함 횟수 계산 공식 페이지 결함 수 = 처음 등장하는 페이지 종류 수 + 교체 횟수 — 서로 다른 페이지가 프레임 수보다 많으면, 그 종류 수에서 시작해 교체가 몇 번 더 생기는지만 세면 됨 📌미니 예제 (풀어본 기출) 참조열 1, 2, 3, 1, 2, 4, 1, 2, 5 · 프레임 4칸 · LRU → 1·2·3·4 첫 등장 결함 4회, 중간 1·2는 전부 적중, 마지막 5에서 교체 1회 (가장 오래 안 쓴 3이 쫓겨남) = 총 5회

프로세스 스케줄링

4과목
용어설명 + 키워드
비선점
Non-preemptive
 한 번 CPU를 잡으면 끝날 때까지 뺏지 않음.
FCFSSJFHRN우선순위(비선점형)
선점
Preemptive
 더 급한 프로세스가 오면 CPU를 뺏을 수 있음. 시분할·실시간 시스템에 적합.
RRSRT다단계 큐다단계 피드백 큐
FCFS
First Come First Served
 먼저 도착한 순서대로 처리. 페이지 교체의 FIFO와 같은 발상.
큐 방식호위 효과(긴 작업 뒤 대기)
SJF
Shortest Job First
 실행 시간이 가장 짧은 작업 먼저. 평균 대기 시간 최소.
짧은 것 우선긴 작업 기아(starvation) 발생
SRT
Shortest Remaining Time
 SJF의 선점형 버전 — 남은 시간이 더 짧은 프로세스가 오면 CPU를 뺏음.
SJF + 선점남은 시간 기준
RR
Round Robin
 시간 할당량(Time Quantum)만큼 돌아가며 실행. 할당량이 크면 FCFS처럼, 작으면 문맥 교환 오버헤드 증가.
시분할 시스템시간 할당량
HRN
Highest Response-ratio Next ★계산
 우선순위 = ( 대기 시간 + 서비스 시간 ) ÷ 서비스 시간, 값이 클수록 먼저 실행 — SJF의 기아 문제를 보완.
예: 대기 20 · 서비스 5 → (20+5)÷5 = 5분모 = 서비스 시간
📌단골 출제 패턴 ① 선점 vs 비선점 분류가 최다 출제 — "비선점 = FCFS·SJF·HRN" 세트로 암기
② HRN 계산 문제는 분모가 서비스(실행) 시간인 것만 기억하면 끝 — 대기 시간이 길수록 우선순위가 올라감
③ "SJF의 단점(기아)을 보완한 기법은?" → HRN
